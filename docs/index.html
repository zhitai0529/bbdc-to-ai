从学习记录到复习 Prompt

助手在本机读取、分类和导出。是否把复习词表发给 AI，由你决定。

  1. 同步本机记录

    连接正在运行的 MuMu，用只读副本读取你自己的「不背单词」学习库，生成本地缓存。数据库还在写入时，会提示你这组学完再同步。

  2. 分类并跨天追踪

    按最近一轮表现分类。若某个词本轮仍模糊，且最近 7 天内有至少 2 个学习日被标为模糊或顽固，默认将它提级为顽固词。

  3. 离线导出，或改好 Prompt

    随时导出结构化 Markdown；也可以在复习预览里改提示词模板，宽窗口下源码与渲染左右对照。

  4. 交给你惯用的 AI

    粘贴到你习惯的对话工具，得到贴合个人词表的阅读短文、例句或测验。用哪家 AI、发不发，由你决定。

运行与同步环境

操作系统
Windows x64 桌面系统。EXE 已内置 Python 运行环境，开箱即用。
同步依赖
需要 MuMu 模拟器 Android 15 与「不背单词」5.11.8 x86。模拟器可从 MuMu 官网 获取，App 装在自己的实例里。App 更新导致 native 库哈希变化时会停止，不假定新版本协议相同。
离线可用
只要本机已生成同步缓存，查词分类、复习预览与导出 Markdown 都能完全离线完成。

清爽的 Material 3 桌面体验，专注复习本身

Flutter 原生窗口，宽屏显示完整导航，窄屏收起侧栏，图表改为纵向排列。

复习总览
学习词量、顽固词排行、24 周学习热力图与熟词占比。点热力图上有记录的日期，即可回看当天的数据。
复习预览
完整 Prompt 的 Markdown 阅读与源码编辑。改动会写回复习文件，重新导出时再按学习记录生成正文。
历史与惯犯词
跨天重复出现的词和当日未确认的编码。哪些词总在同一个坑里，一眼就能看出来。
外观主题
日间、夜间、跟随系统三态，切换立即生效，下次启动自动恢复；首次启动默认跟随 Windows 设置。

三步开始第一次提取

首次配置需要一点耐心；之后每天只需要同步、复制两步。

  1. 在电脑端备好模拟器

    装好 MuMu Android 15 与「不背单词」5.11.8 x86，在 App 里登录自己的账号。细节见配置指南。

  2. 运行 EXE 并同步

    双击 bbdc-to-ai-windows-x64.exe，先点「一键配置 MuMu」，再点「同步 MuMu」。

  3. 复制 Prompt，或导出留存

    打开复习预览点「复制全部内容」发给 AI，或「导出今日复习」把 Markdown 存进 Obsidian 等笔记软件。
